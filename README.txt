EPIC INDIA BIO SCIENCE WEBSITE
===============================

Files:
- index.html       Homepage
- aboutus.html     About page
- products.html    Product catalogue layout
- services.html    Services page
- gallery.html     Photo gallery
- contact.html     Contact form and contact details
- styles.css       Shared responsive design and sticky mobile CTA
- script.js        Mobile navigation, reveal animation, enquiry form helper

HOW TO USE
1. Keep all HTML files, styles.css and script.js in the same folder.
2. Open index.html in your browser to preview.
3. Upload all files to the same hosting directory (often public_html).
4. Replace placeholders before publishing:
   - 901390xxxx (call number)
   - xxxxxxxx (WhatsApp number)
   - xxxxx (email)
   - address placeholder
   - social links (#)
   - sample product/service copy and stock photos
5. Contact form currently opens the visitor's email app. Update the recipient in script.js from 'xxxxx' to the real email.
6. Gallery contains 12 temporary images and can be expanded to ~50 images when supplied.

NOTE
The number provided is masked, so the Call link will not dial correctly until you insert the full number. Photos currently load from Unsplash and need an internet connection. Product/service claims are placeholders; replace with verified company information.
